# Zip Slip = Path Traversal через имя файла в архиве.
Механика: вредоносный zip содержит файл с именем-путём ../../../hooks/evil.sh (не просто имя, а путь с ../). Приложение при распаковке: папка_распаковки + имя_из_архива. Если имя = ../../, файл выскальзывает ЗА пределы папки распаковки в произвольное место.
Корень: приложение НЕ проверяет, что распакованный путь остаётся ВНУТРИ целевой папки (доверяет имени файла из архива).
*Это разновидность PATH TRAVERSAL* (тот же ../, что ?file=../../etc/passwd, но в архиве).
Импакт: произвольная запись файла → RCE (положить в исполняемую/hooks папку), перезапись конфигов, и т.д. Zip Slip = запись; следствие зависит от того, КУДА положил.
Защита: проверять, что итоговый путь распаковки внутри целевой папки (canonical path startswith target dir); отклонять файлы с ../. Allowlist по пути.
