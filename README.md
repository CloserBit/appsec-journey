# appsec-journey

Мой путь подготовки на позицию **AppSec Engineer**: конспекты, скрипты-автоматизации
и write-up'ы уязвимостей. Репозиторий растёт по мере прохождения роадмапа (~4 месяца).

## Цель
Уверенно находить, эксплуатировать и чинить топ-уязвимости веб-приложений и API;
встраивать SAST/DAST/SCA в CI/CD; вести триаж и приоритизацию находок.

## Стек и инструменты
Python · Burp Suite · OWASP ZAP · Nuclei · Semgrep · Trivy · Postman · Docker

## Структура
- `notes/`    — конспекты по темам (HTTP, OWASP Top 10, API Security и т.д.)
- `scripts/`  — питон-автоматизации для тестов
- `writeups/` — разборы уязвимостей в формате баг-репорта (шаги, impact, fix)
- `labs/`     — заметки по лабам (PortSwigger, THM, HTB)
